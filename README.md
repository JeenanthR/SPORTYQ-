SportyQ - AI-Powered Sports Trivia Companion



SportyQ is an interactive web application designed to challenge and improve your sports knowledge through a gamified quiz experience. It features AI-generated questions across multiple sports categories, user authentication, and a dedicated management panel.



🚀 Features

Smart AI-Generated Questions: Dynamic trivia questions generated for various sports.

Multiple Arenas: Specialized categories for Football, Cricket, NBA, and Tennis.

Dual Game Modes:

AI Mode: Challenges you with smart, generated questions.

Manual Mode: Classic questions curated by the system.

User System: Secure Sign In and Sign Up functionality for players.

Admin Panel: A restricted area for managing, adding, and refreshing the question database.

Interactive UI:

Responsive design using the Poppins font.

Real-time score tracking.

Celebration effects (confetti, fireworks) for high-performance milestones.

Sliding image gallery on the welcome page.



🛠️ Tech Stack

Frontend: HTML5, CSS3, JavaScript (ES6+).

Styling: Custom CSS with Google Fonts (Poppins) and Font Awesome icons.

Storage: Browser LocalStorage for user accounts and custom question management.
