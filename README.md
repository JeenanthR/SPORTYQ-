# 🏆 SportyQ - AI-Powered Sports Trivia Companion

**SportyQ** is an interactive web-based quiz application designed to test and improve your sports knowledge through a fun, gamified experience. With AI-generated questions, multiple sports categories, and engaging UI effects, SportyQ makes learning sports trivia exciting and competitive.

---

## 🚀 Features

### 🤖 Smart AI-Generated Questions

* Dynamically generated trivia questions across different sports.
* Keeps the quiz fresh and challenging every time.

### 🏟️ Multiple Arenas

* Football ⚽
* Cricket 🏏
* NBA 🏀
* Tennis 🎾

### 🎮 Dual Game Modes

* **AI Mode** – Play with dynamically generated questions.
* **Manual Mode** – Attempt pre-defined classic questions.

### 👤 User Authentication

* Secure **Sign Up** and **Sign In** system.
* Tracks individual user progress.

### 🛠️ Admin Panel

* Restricted access for administrators.
* Add, edit, and refresh quiz questions.
* Manage the question database efficiently.

### 🎨 Interactive UI

* Fully responsive design.
* Stylish interface using **Poppins font**.
* Real-time score tracking.
* 🎉 Celebration effects (confetti & fireworks) for achievements.
* 🖼️ Sliding image gallery on the welcome page.
